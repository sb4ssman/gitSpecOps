plugins-remote/
github gitlab gitea plain-git

Chosen by the remote URL. Basic names no host, so a second host is a new folder rather than a rewrite — this is how git-agnostic actually happens.

plugins-local/
platform editors git-clients

Chosen by detection, never configured. Windows, Linux and macOS are peers — adding one is adding a folder, and no caller ever branches on OS. The tray reaches it too.

App/skins/
modern retro lcars

The one genuine choice. A skin consumes the versioned display contract and refuses a version it does not know; it never reimplements Git policy.

BUILDS ONLY ON WHAT IS ABOVE

A layer uses only the layers above it — never sideways, never what comes after. A test reads the imports and says so.

NOTHING IMPORTS A PLUGIN

import plugins-remote is a syntax error. Plugins load by path, so no layer can depend on one.

WATCHING CHANGES NOTHING

The peer, tray and dashboard only observe. Every change is a command you invoked, planned and confirmed.
